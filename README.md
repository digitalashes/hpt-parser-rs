# hpt-parser

A Rust parser for CMS Hospital Price Transparency machine-readable files: CSV (tall and
wide) and JSON, data dictionary versions 2.0.0 to 3.0.0.

> **Unofficial.** This project is not affiliated with, endorsed by, or maintained by the
> Centers for Medicare & Medicaid Services.

**Work in progress.** There is no API yet.

To check that a file follows the data dictionary, use
[`hpt-validator`](https://github.com/digitalashes/hpt-validator-rs) or its command line,
[`hpt-validator-cli`](https://github.com/digitalashes/hpt-validator-cli-rs).
